# Darian Prellwitz — Figma Portfolio

A personal portfolio landing page converted from a Figma design into HTML and CSS, rebranded with my own content.

## About

This project was completed as a final module assignment. The original Figma design was translated into a fully hand-coded static webpage, then customized with my own name, bio, profile photo, and branding.

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom layout and styling (no frameworks)
- **Google Fonts** — Raleway & IBM Plex Mono

## Features

- Responsive navigation bar with social links (LinkedIn, Behance, Twitter)
- Hero section with intro text and CTA button
- "Worked With" logo strip showcasing client/brand logos
- Dark-themed design with a clean, minimal aesthetic
